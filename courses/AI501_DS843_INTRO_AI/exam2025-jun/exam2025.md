## Question 1
Which type of environment are most suitable for AND–OR trees?

- [ ] Unknown environments
- [x] Nondeterministic environments
  > AND–OR search trees (AIMA §4.3) are built for nondeterministic actions: OR nodes are the agent's choices, AND nodes are the outcomes a plan must cover.
- [ ] Online environments
- [ ] Non-observable environments
  > A sensorless (non-observable) problem is solved by ordinary search over belief states; with no percepts there is nothing to branch on, so no AND nodes are needed.

## Question 19
Which of the following is a limitation of the standard minimax algorithm?

- [x] It is inefficient for games with large search trees due to exhaustive exploration.
  > Minimax explores the whole game tree depth-first, $O(b^m)$ time, which is impractical for real games; hence alpha–beta pruning and depth cut-offs.
- [ ] It is only applicable to games with imperfect information.
- [ ] All of the other answers
  > Minimax assumes perfect information, so the second option is false, and with it this one.
- [ ] It can not easily be adapted to handle games with more than two players.
  > Extending minimax to more players is straightforward: each node holds a vector of utilities, one per player (AIMA §5.2).
